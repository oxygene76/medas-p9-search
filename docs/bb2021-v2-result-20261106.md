# V2 result: the short runs of sets A and B are outside the limits (2026-11-06)

The condition V2 of `docs/bb2021-comparison-criteria.md` (addenda 13 and 16, fixed before any short run; addendum 16
entered as entry e4 = chain entry #5, block 10728476): before the 4-Gyr run of a set, a short run of that set must show
an encounter regime like that of the equivalence runs.

**Verdict:** set A and set B are both **outside the limits**.
- As the criteria fix it, neither 4-Gyr run starts.
- Each set first needs a paired test V5 against MERCURIUS with criteria fixed beforehand.
- The project lead accepted the verdict on 2026-11-06. The limits are not changed afterwards.

## The evaluation

- **Tool:** `tools/v2_encounter_check.py` at commit `eae402e` (eae402e4fa39f68946683188471a772dac472c52, 2026-11-04;
  file sha256 `af5ffd7c15d898a63b425c029209bf4cda73f1604956354c4b3b3f09b4755ee3`), unchanged since.
- **Command:**
  ```sh
  python3 -I tools/v2_encounter_check.py jobs/V2-A jobs/V2-B --ok-dir v2
  ```
- **What it counts:** the share of the test particles with at least one flyby shorter than 1.5 steps ("fast") and
  with at least one within 0.1 au ("close"), per planet, over 0–60 Myr.
- **Recount:** an independent count of the same flyby logs with awk gave the same twelve values.

**Limits** (addendum 13): Neptune and Uranus within ±30 % of the reference, Planet Nine at most twice the reference;
all six must hold.

| | reference (equivalence runs V5, 9 × 4,000, 0–60 Myr; addendum 13) | set A | set B |
|---|---|---|---|
| Neptune fast | 17.61 % | 19.39 % (× 1.10) ok | 13.39 % (× 0.76) ok |
| Neptune close | 4.47 % | 4.34 % (× 0.97) ok | 4.00 % (× 0.89) ok |
| Uranus fast | 2.75 % | **5.56 % (× 2.02) out** | **1.70 % (× 0.62) out** |
| Uranus close | 0.84 % | **1.39 % (× 1.66) out** | 0.72 % (× 0.86) ok |
| Planet Nine fast | 1.09 % (limit 2.18 %) | 0.48 % ok | 2.14 % ok |
| Planet Nine close | 0.26 % (limit 0.52 %) | 0.14 % ok | 0.39 % ok |

- With 16,000 test particles the seed-to-seed spread of the Uranus shares is about ±8 % (addendum 16: ±17 % at
  4,000).
- The deviations of set A (× 2.02 and × 1.66) and set B (× 0.62) are far outside it.

## What follows (as fixed in addenda 13 and 16)

- **The 4-Gyr runs of sets A and B are not started.** Before either, a paired test V5 against MERCURIUS for that set,
  with its own criteria fixed and entered on chain before it starts. A proposal for them is in
  `docs/bb2021-paired-test-proposal.md`.
- **Not affected:**
  - The production run. Its method was decided by the equivalence test at its own configuration (entry e3).
  - The paired long runs of seeds 110–112.
- **Not done:** the limits are not changed, the short runs are not repeated with other seeds, and the number of test
  particles is not raised after the result.
